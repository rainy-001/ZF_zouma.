## 一、控制架构

```
摄像头 → image_proc() → onto (偏差角, -30°~+30°)
                              ↓
                     pid_angle.compute(onto, 0)
                              ↓
                        onto_control (方向修正量)
                       ↙              ↘
        左轮期望 = V_cruise + onto_control
        右轮期望 = V_cruise - onto_control
                       ↓
          ladrc_left / ladrc_right (速度环, 1ms周期)
                       ↓
                    PWM → 电机
```

| 控制器 | 负责 | 周期 | 优先级 |
|--------|------|------|--------|
| PD (`pid_angle`) | 方向/转向 | 10ms | 97 |
| LADRC (`ladrc_left/right`) | 速度跟踪 | 1ms | 99 |

**调试顺序：先 LADRC 速度环，后 PD 方向环。速度环跟不上，方向环调再好也没用。**

## 二、LADRC 调参

### 2.1 算法简介（一阶 LADRC）

LADRC = TD（跟踪微分器）+ ESO（扩展状态观测器）+ LSEF（线性反馈律）

```
目标速度 → [TD]  → v1(平滑目标)  → [LSEF] → u → [电机] → 实际速度
                                    ↑          ↓
实际速度 → [ESO] → z1(估计速度)   →┘          z2(总扰动估计)
```

每步 `update(target, actual)` 执行：

```
TD:  v1 += v2 * h
     v2 += [-r²(v1 - target) - 2r·v2] * h     // 平滑跟踪目标

ESO: e  = z1 - actual
     z1 += (z2 - 2w0·e + b0·u) * h            // 估计实际速度
     z2 += (-w0²·e) * h                        // 估计总扰动

LSEF: u0 = wc * (v1 - z1)                      // 比例控制
      u  = (u0 - z2) / b0                       // 补偿扰动 ÷ 系统增益
```

### 2.2 五个参数

| 参数 | 默认值 | 含义 | 类比 |
|------|--------|------|------|
| `h` | 0.001 | 积分步长 = 线程周期 (1ms)，不动 | 采样周期 |
| `r` | 20 | 跟踪速度因子，越大目标跟踪越快 | 斜坡函数 |
| `wc` | 33 | 控制器带宽，越大响应越快 | 类似 P |
| `w0` | 133 | 观测器带宽，越大扰动估计越快 | 类似 I+D |
| `b0` | 8.0 | 系统增益：1单位PWM产生的速度变化 | PID 无对应 |

**关键关系：w0 ≈ 3~10 × wc**

### 2.3 调参步骤

#### 第一步：测 b0（最重要，PID 没有的步骤）

```
方法：开环给固定 PWM，读编码器速度
b0 = 速度(m/s) / PWM值

示例：
  PWM=300 → 速度 0.5 m/s → b0 = 0.5/300 ≈ 0.0017
  PWM=500 → 速度 0.8 m/s → b0 = 0.8/500 ≈ 0.0016

取多次测量平均值。b0 不准，LADRC 表现大打折扣。
```

#### 第二步：调 wc（响应速度）

```
初始 wc = 5~10
给阶跃目标 (如 0 → 0.3 m/s)，观察响应：
  - 太慢 → 加大 wc (×1.5~2)
  - 振荡 → wc 过大，退回
```

#### 第三步：调 w0（扰动抑制）

```
w0 = 3×wc 起步，逐步加到 5×wc
  - 跟踪精度提高 ✓
  - 出现高频抖动 → w0 过大，退回
```

#### 第四步：调 r（平滑度）

```
r ≈ wc 起步
  - 阶跃有超调 → 减小 r
  - v1 跟不上 target → 加大 r
```

#### 第五步：h 不动

```
h = 0.001 = LARDC_PERIOD (1ms)，已最优
```

### 2.4 预设参数表

```cpp
//          h      r     wc    w0    b0
预设 0:  {0.005, 20.0, 100.0, 400.0, 0.5}   // 激进
预设 1:  {0.001, 20.0,  33.0, 133.0, 8.0}   // 默认 ★
预设 2:  {0.005, 100.0, 20.0,  80.0, 0.5}   // 保守
预设 3:  {0.005, 100.0, 14.0,  57.0, 0.5}   // 更保守
```

### 2.5 常见问题

| 症状 | 原因 | 解法 |
|------|------|------|
| 速度跟不上目标 | wc 太小 | ↑wc |
| 稳态有偏差 | w0 太小 / b0 不准 | ↑w0，重新测 b0 |
| 速度振荡 | wc 太大 | ↓wc |
| 响应抖动 | w0 太大 / r 太小 | ↓w0 或 ↑r |
| 启动有超调 | r 太小 | ↑r |

## 三、PD 方向环调参

### 3.1 算法

```cpp
// my_pid.cpp PDController::compute()
error = target - actual;           // 0 - onto = -onto
error_delta = error - last_error;  // 偏差变化率

output = error × Kp × weight           // ① 分段线性 P
       + error × |error| × Kp2        // ② 非线性 P²
       + error_delta × Kd;            // ③ 微分 D

output = clamp(output, -limit, +limit);
```

#### ① 分段线性 P

4个区间按 |error| 比例分段，各有权重。当前四段均为 0.70：

```
|error|/limit ≤ 25% → weight=0.70  (小偏差)
              ≤ 50% → weight=0.70  (中小偏差)
              ≤ 75% → weight=0.70  (中大偏差)
              > 75% → weight=0.70  (大偏差)
```

当前 `onto_kp = 0.0`，线性 P **未启用**。

#### ② 非线性 P²（核心）

P² = Kp2 × error × |error|，输出与偏差平方成正比：

| 偏差角 | P² 输出 (onto_kp2=0.65) | 效果 |
|--------|-------------------------|------|
| 5° | 0.65 × 5 × 5 = **16** | 直道微调 |
| 15° | 0.65 × 15 × 15 = **146** | 中等弯道 |
| 30° | 0.65 × 30 × 30 = **585** | 急弯猛打 |

天然适配赛道：弯道自动加大力度，直道自动减小。

#### ③ 微分 D

`onto_kd = 4.0`，抵抗偏差快速变化，作用是**抑制振荡、增加阻尼**。

### 3.2 参数表

| 参数 | 默认值 | 作用 |
|------|--------|------|
| `onto_kp` | 0.0 | 线性 P，一般不需要 |
| `onto_kp2` | 0.65 | 非线性 P²，核心调参项 |
| `onto_kd` | 4.0 | 微分阻尼 |
| `onto_limit` | 45.0 | 输出限幅 ±45 |

### 3.3 调参步骤

#### 第一步：调 Kp2（转向力度）

```
Kp2 = 0 起步
每步 +0.05~0.1，直到直道稳定、弯道能转过去
  - 直道左右摇摆 → Kp2 过大，退回
  - 弯道转不过去 → Kp2 不够，继续加
```

#### 第二步：调 Kd（阻尼）

```
Kd = 0.5 起步
  - 小车摆头（高频左右晃） → 加大 Kd (每次 +0.5)
  - 转弯太"肉"、响应迟钝 → 减小 Kd
```

#### 第三步：微调分段权重（可选）

如果需要在特定误差区间调整灵敏度，修改 `weight[4]` 数组：

```cpp
weight[0] = 0.5   // 小偏差时降低灵敏度（减少直道振荡）
weight[1] = 0.7
weight[2] = 0.9   // 大偏差时提高灵敏度（加强弯道响应）
weight[3] = 1.0
```

#### 第四步：确认限幅

```
out_limit = 45
如果弯道始终转不过、onto_control 频繁打满 → 可能是 Kp2 不够，而非限幅问题
如果直道也出现大幅转向 → 减小限幅保安全
```

### 3.4 Kp2 与 Kd 配合规律

| 症状 | 原因 | 解法 |
|------|------|------|
| 直道左右摇摆 | Kp2 过大 / Kd 过小 | ↑Kd 或 ↓Kp2 |
| 弯道转不过去 | Kp2 过小 | ↑Kp2 |
| 弯道过冲（甩尾） | Kp2 过大 | ↓Kp2 + ↑Kd |
| 转弯太慢/迟钝 | Kd 过大 | ↓Kd |
| 高频抖动 | Kd 太小 | ↑Kd |

## 四、联动调试

PD 输出 `onto_control` 直接叠加在 LADRC 速度期望上：

```cpp
左期望 = cruising_speed + onto_control  // 修正量 > 0 → 左轮加速 = 右转
右期望 = cruising_speed - onto_control  // 修正量 > 0 → 右轮减速 = 右转
```

### 联动调参顺序

```
1. 先调 LADRC 速度环（1ms周期）
   b0 (测准) → wc → w0 → r

2. 再调 PD 方向环（10ms周期）
   Kp2 → Kd

3. 联调
   在赛道上跑一圈，观察：
   - 直道：速度波动 < 5%，无摇摆
   - 弯道：转向及时，无甩尾
   - 出弯：速度快速恢复，无振荡
```

### 调试工具

- **vofa+ 实时调参**：通过 TCP 远程读写参数，不用重新编译
- **IPS200 屏幕帧率显示**：确认图像处理帧率不影响控制
- **摄像头帧率**：59fps（当前），10ms PD 周期 = 100Hz 检查，每帧都处理
