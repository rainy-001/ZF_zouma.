# 串级 PID 调参指南

> 控制模式：`control_model=0`（PID 模式）  |
> 平台：LS2K0300  |  周期：2026-06-16

---

## 一、架构总览

```
┌─────────────────────────────────────────────────────────────┐
│                      串级控制回路                            │
│                                                             │
│  image_proc ─→ onto ─→ [pid_angle] ─→ onto_ctrl            │
│    (50Hz)          │      PD方向环          │               │
│                    │     (10ms/prio97)       │               │
│                    │                        ↓               │
│                    │  左期望 = cruising + onto_ctrl          │
│                    │  右期望 = cruising - onto_ctrl          │
│                    │         │                              │
│                    │         ↓                              │
│                    │  [pid_l / pid_r] ──→ motor_set_speed    │
│                    │    PID速度环             → PWM → 电机   │
│                    │   (10ms/prio97)                        │
│                    │         ↑                              │
│                    │  encoder_get (2ms/prio99)               │
│                    │  → left_speed / right_speed            │
└─────────────────────────────────────────────────────────────┘
```

**调参铁律：先调内环（速度），后调外环（方向）。内环不稳，外环白调。**

## 二、参数清单

### 2.1 速度环 PID（`pid_l` / `pid_r`）

配置文件 `car_config.txt` 中 `pid_r:` / `pid_l:` 行：

| 参数 | 默认值 | 作用 | 调大效果 |
|------|--------|------|----------|
| `p` (Kp) | **2.5** | 比例增益 | 响应快，过大振荡 |
| `t` (Ts/Ti) | **0.015** | 积分时间常数 | 积分作用敏感度 |
| `i_gain` (Ki) | **1.1** | 积分增益 | 消静差快，过大超调 |
| `d` (Kd) | **1.2** | 微分增益 | 加阻尼，过大迟钝 |
| `error_filter` | **1.1** | 死区 | 过滤小误差噪声 |
| `output_max/min` | **±120** | 输出限幅 | 保护，不参与控制 |
| `integral_max/min` | **±60** | 积分限幅 | 防饱和 |

`car_config.txt` 示例：
```ini
pid_r: p=2.5f,t=0.015f,i_gain=1.1f,d=1.2f,error_filter=1.1f,output_max=120f,output_min=-120f,integral_max=60f,integral_min=-60f;
pid_l: p=2.5f,t=0.015f,i_gain=1.1f,d=1.2f,error_filter=1.1f,output_max=120f,output_min=-120f,integral_max=60f,integral_min=-60f;
```

### 2.2 方向环 PD（`pid_angle`）

vofa+ 可实时调参：

| 参数 | 默认值 | vofa 按钮 | 作用 |
|------|--------|-----------|------|
| `onto_kp` | 0.0 | adjust kp | 线性 P（一般不用） |
| `onto_kp2` | **0.65** | adjust kp2 | 非线性 P²，核心 |
| `onto_kd` | **4.0** | adjust kd | 微分阻尼 |
| `onto_limit` | **45.0** | adjust limit | 输出限幅 |

### 2.3 巡航速度

`my_global.hpp`：
```cpp
#define CRUISING_SPEED 0.3   // m/s，调参时建议 0.2~0.5
```

## 三、调参步骤

### 第一步：速度环 Kp（最重要）

```
条件：车架起来，轮子悬空
目标：阶跃响应快且不振荡

① 关闭 I 和 D：
   car_config.txt 中设 i_gain=0f, d=0f

② Kp 从 1.0 起步：
   每次 +0.5，观察编码器速度跟随情况

③ 判断标准：
   响应快、无超调 → 继续加
   出现振荡/超调 → 退回上次值 ×0.7
   最终值通常在 1.5 ~ 4.0 之间
```

### 第二步：速度环 Ki（消静差）

```
① 在第一步最佳 Kp 基础上，加 Ki：
   i_gain 从 0.5 起步，每次 +0.3

② 判断标准：
   稳态误差快速消除 ✓
   出现超调+来回振荡 → Ki 过大，退回
   最终值通常在 0.5 ~ 2.0

③ 积分限幅保护：
   integral_max/min = ±60（已设）
   防止长时间偏差导致积分饱和失控
```

### 第三步：速度环 Kd（加阻尼）

```
① 在 Kp、Ki 确定后，加 Kd：
   d 从 0.5 起步，每次 +0.3

② 判断标准：
   振荡被抑制 ✓
   响应变迟钝 → Kd 过大，退回
   通常 Kd ≈ Kp × 0.3 ~ Kp × 0.8
```

### 第四步：方向环 PD

```
条件：车落地，直道慢速巡航
工具：vofa+ 实时调参

① Kp2（非线程 P²）：
   从 0.1 起步，每次 +0.05
   直道稳、弯道能转 = 最佳
   左右摇摆 → 退回

② Kd（微分阻尼）：
   从 0.5 起步，每次 +0.5
   摆头 → 加大
   转弯迟钝 → 减小

③ 限幅：
   onto_limit 默认 45，一般不动
   弯道始终转不过 + onto_ctrl 打满 → 先加 Kp2
```

### 第五步：联调

```
实跑一圈观察：

直道：速度波动 <5%，无摇摆
弯道：转向及时，不甩尾
出弯：速度快速恢复，无振荡

问题定位：
  速度跟不上 → 内环 Kp/Ki 不够
  转向不够 → 外环 Kp2 不够
  转向过冲 → 外环 Kp2 过大 / Kd 不够
  出弯振荡 → 内环 Kd 不够 / Ki 过大
```

## 四、快速调试口诀

```
① 关 I 关 D，纯 P 起步找到临界振荡 → 退回 30%
② 开 I 消静差，逐步加到刚好消除
③ 开 D 加阻尼，有振荡就加，变迟钝就减
④ 落地调方向，Kp2 管力度，Kd 管平稳
```

## 五、调参技巧

| 技巧 | 方法 |
|------|------|
| **编码器看速度** | vofa+ 波形看 right_speed/left_speed 跟随 target_speed 的响应 |
| **调试先悬空** | 车轮离地，排除地面摩擦干扰 |
| **低速起步** | `CRUISING_SPEED=0.2` 开始，稳了再加速 |
| **左右分开调** | 左右轮可以设不同的 PID 参数（机械差异） |
| **改完要写回** | 改 `car_config.txt` 后 vofa 点 WRITE 保存 |

## 六、常见问题速查

| 症状 | 原因 | 解法 |
|------|------|------|
| 速度跟不上目标 | Kp 太小 / Ki 太小 | ↑Kp，↑Ki |
| 速度超调后振荡 | Kp 太大 / Kd 太小 | ↓Kp，↑Kd |
| 稳态有静差（速度达不到目标） | Ki 太小 | ↑Ki |
| 启动冲击大 | Kp 太大 | ↓Kp，↑Kd |
| 低速抖动/嗡嗡响 | error_filter 太小 | ↑死区到 1.5~2.0 |
| 长时间偏差后失控 | Ki 太大，积分饱和 | ↓Ki，↓integral_max |
| 直道左右摇摆 | Kp2 过大 / Kd 太小 | ↓Kp2 或 ↑Kd |
| 弯道转不过去 | Kp2 过小 | ↑Kp2 |
| 弯道甩尾 | Kp2 过大 | ↓Kp2 + ↑Kd |
| 出弯速度振荡 | 速度环 Kd 不够 | ↑Kd |

## 七、参数联动关系

```
速度环：Kp 决定响应速度，Ki 决定精度，Kd 决定稳定
        Kp : Ki : Kd ≈ 2.5 : 1.0 : 1.0（典型比例）
        
方向环：Kp2 决定转向力度，Kd 决定平稳度
        Kp2 : Kd ≈ 0.15 : 1.0（典型比例）

两个环独立：
  - 速度环慢（跟不上）→ 方向环输出落不到轮子上 → 转弯迟钝
  - 方向环慢（onto_ctrl 小）→ 速度差不够 → 转不过弯
```
